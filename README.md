# 云图计划 AVG 剧情播放器 · 编辑器 —— 新手导读

> 本页是面向新人的快速上手导读。想深入了解保真方法论、回归矩阵、引擎设计等技术细节，请继续阅读 [INTRO.md](INTRO.md)。

## 这是个什么东西？

一句话：**它把手游《云图计划》的剧情演出"搬"到了网页上，让你不仅能重看每一段剧情，还能像一个可视化的剪辑台一样自由改写、自制剧情，最后打包成一个可以发给朋友、双击就能看的独立小网页。**

先铺垫三个名词：

- **AVG**：游戏里那种"背景图 + 角色立绘 + 对话框 + 选项分支"的视觉小说式演出。《云图计划》的 AVG 做得相当精致——有立绘入场动画、镜头移动、背景音乐、音效，甚至日文配音。
- **GFWiki**：游戏的中资料站（灰度wiki）。站上有个叫 `AvgPlayer` 的小工具，能在网页里直接重放游戏剧情。**本项目的核心，就是把那个网页播放器做到和原版一模一样（像素级复刻），再在它之上加一套完整的编辑器。**
- **复刻 + 扩展**：原版播放器只能"看"，这个项目让它还能"改"——背景、音乐、说话人、台词、立绘，全都可视化编辑。

## 你能用它做的三件事

1. **回看剧情**：内置官方全部 **1878 段剧情**（主线、活动、个人线……），从"剧本库"里搜索点选即可装载播放，背景/立绘/音乐/配音全套还原。想回看某个角色的好感度语音剧情？搜一下就播。
2. **改写或自制剧情**：编辑器里每一句台词、每一张背景、每一段音乐都是可编辑的"分镜卡片"。支持撤销/重做、时间线视图、立绘位置标定，改动即时预览——**不需要写任何代码**。
3. **打包带走**：做好的剧情可以导出为三种形态（单个 JSON 工程文件、ZIP 包、独立目录站），全都自带音频和播放器，发给任何人都能离线打开观看。

## 三步跑起来

这个项目**没有任何安装步骤**——不依赖 npm、不需要编译，整个仓库就是一个"解压即用"的静态网站。注意要先 clone 完整仓库：素材直接随仓库分发，体积有几个 GB。

```bash
# 第 1 步：装好 Python（只用它起个本地服务器）
# 第 2 步：在项目根目录执行
python tools/ref/serve.py 8080
# 第 3 步：浏览器打开
#   http://127.0.0.1:8080/index.html   ← 编辑器（主入口）
#   http://127.0.0.1:8080/cal.html     ← 立绘位置标定工具
```

打开编辑器后：点顶栏**「剧本库」**选一段官方剧情 → 加载进编辑器 → 左边改文案、右边调立绘和音乐 → 顶栏预览播放。就这么简单。

用其他任意静态服务器指向本仓库根目录也可以照常运行（`tools/ref/serve.py` 额外提供 wiki 素材代理与测试用的冻结通道，日常把玩剧情用不到）。

## 剧情和素材是哪来的？

全部提取自游戏本体：1878 段剧情在游戏里是编译过的 Lua 字节码，本项目自研了一个解码器把它们还原成可读的指令流；731 张背景/CG、500+ 名角色的立绘与表情差分、全套 BGM/音效/日文剧情语音（已转码为通用的 ogg 格式）也一并入库。所以 clone 下来就拥有完整体验，不依赖游戏、不依赖外网。

## 目录里都是什么？

| 位置 | 是什么 |
|---|---|
| `index.html` / `cal.html` | 编辑器主页面 / 立绘标定工具 |
| `selftest-*.html` | 十来个"自检页"，平时不用管，是自动化测试用的 |
| `js/` | 全部程序代码（播放引擎、编辑器、解码器），纯原生 JavaScript |
| `css/` | 样式（其中两份是从原版逐行对照移植的，保证长得一样） |
| `data/` | 剧情夹具、素材索引、转码好的音频、字体、UI 贴图 |
| `res/` | 游戏素材本体（背景/立绘/剧情脚本，几个 GB 的大头） |
| `tools/` | 自动化测试脚本和素材处理工具（纯 Node 脚本，无第三方依赖） |

## 凭什么说"复刻得很准"？

这是本项目最有意思的地方：它不是"看着像就行"，而是**机器对拍**。开发者把原版 wiki 播放器放进无头浏览器里跑一遍，把每个环节的状态录下来存成"标准答案"（称为**冻结表**）；然后让自己写的播放器跑一模一样的内容，把结果和标准答案逐项比对——播放器一套测试就有 2000+ 条断言，全套 20 多个测试文件、数千条断言全绿，才算"复刻完成"。所以改动代码之后，跑一遍 `node tools/test-*.mjs` 就知道有没有把东西改坏，不用肉眼去猜。
